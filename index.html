How it works

From bundle to findings in three steps

1

Install & launch

Download Nexara and start it — your browser opens at 127.0.0.1:8443. Everything runs locally; there's nothing to sign in to.

2

Pick a product, drop the bundle

Choose SSR, SRX or EdgeConnect and drop the bundle. For SSR, pick single router, conductor or HUB + Spoke; drop both HA nodes together.

3

Read, debug & share

Work through the insights, drill into sessions, crashes and telemetry, then export an RCA report for the case.

Questions

FAQ

Does my bundle leave my computer?

No. Nexara runs on 127.0.0.1 and works fully offline. The only feature that sends anything out is Agentic Debug — and only if you add your own AI provider and start an investigation.

Do I need an account?

No. There's no sign-up and no login — install it and drop a bundle.

What can I upload?
  • SSR / 128T: TSI .zip — single router, conductor, both HA nodes, or a HUB and Spoke pair
  • SRX: RSI output, a /var/log archive and/or config
  • EdgeConnect: ECOS sysdump .tgz

Up to 10 GB per file and 5 bundles at a time. Nested archives are unpacked automatically.

Is AI required?

No. Every indicator, chart and RCA is deterministic and runs locally. Agentic Debug is an optional extra for SSR bundles.

Which operating systems are supported?

macOS (.dmg) and Windows (installer .exe). It can also run from source anywhere Python runs.
